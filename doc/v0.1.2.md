## 为了让 sqlm 真正适配 PostgreSQL 做的库改动

原来 `Table` 层是写死 MySQL 方言的（反引号 + `?` + `LastInsertId`），Postgres 上必然报错，所以按协议做了分支（`const.go` 新增 `POSTGRES`/`PG`）：

- `table.go`：标识符引用双引号化（`Insert`/`Inserts`/`Update`），占位符改为 `$n` 且**跨多行连续编号**（`INSERT ... VALUES ($1,$2),($3,$4)`）；
- `PostgreSQL` 没有 `LastInsertId`，`lastInsertID()` 在驱动报错时回退为受影响行数，不再让写入失败；
- `Limit`/`LimitOffset` 对非 MySQL 协议输出标准 `LIMIT .. OFFSET ..`；
- `escape()` 对 Postgres 不再转义反斜杠（`standard_conforming_strings` 下它是普通字符）；
- `store.NewDriver` 支持 `postgres`/`pg`（上一轮的 `store/postgres.go`），依赖新增 `github.com/lib/pq v1.10.9`，注意 **`Server.Protocol` 必须等于驱动注册名**（即 `"postgres"`）。
